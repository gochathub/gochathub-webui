# Attachments

## Send a file

Press the paperclip in the message box. In the window that opens, choose Select files, pick one or more files, and confirm. The files wait above the message box. Add text if you want, then send.

Each file uploads straight to the server's storage before the message goes out. A large file can take a moment. Remove a file from the waiting list to leave it out.

## Size limits

The server's administrator sets the maximum file size. If a file is too big, you see "Upload failed. The file may exceed the size limit." Try a smaller file, or ask your administrator whether the limit can change.

If you see "Attachment storage is not available on this deployment," the server has no file storage configured. Only an administrator can fix that.

## Shared media

Open Conversation info and choose Shared Media to browse the images, videos and documents sent in a conversation.

## Download links expire

Download links are short-lived. If an image or file stops opening after the page has been idle for a while, reload the conversation and it gets a fresh link.
