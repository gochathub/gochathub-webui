# Account and security

All of these live under Settings.

## Display name

Open Account, edit Display name, and press Save Settings.

## Change your password

In Account, fill in Current password and New password, then press Update password. This signs you out everywhere, on every browser and phone, and sends you to the sign-in page. Sign in again with the new password.

If you see "Wrong current password or new password too short," check the first and make the second longer.

## Two-factor authentication

Two-factor authentication adds a code from an authenticator app to your sign-in.

To turn it on:

1. In Account, press Set up under two-factor.
2. Scan the code with your authenticator app. If you cannot scan, type the secret shown under the code.
3. Enter the 6-digit Code and press Turn on.
4. Save the backup codes. Each one works once, and they are not shown again.

To turn it off, press Turn off and confirm with your password and a current code. New backup codes replaces your old set after you enter a current code.

If you lose your device, sign in with a backup code. If you have none left, ask your administrator.

## Sign in on your phone with a QR code

In Account, press Create QR code and scan it in the goChatHub mobile app (Sign in, then Scan QR). It signs the phone in without a password or two-factor code.

Treat it like a password. Anyone who scans it can use your account. It is shown once, so press Done when you have scanned it.

Below the button is a list of the sign-ins you created, with the last time each was used. Press Revoke to cut one off.

## Privacy

Under Privacy and Safety:

- Show Last Seen lets people see your last login.
- Show Read Receipt lets people see whether you have read their messages. See [Read receipts](/help/read-receipts).
- Joining Groups lets people add you to groups.
- Private Messages lets people who are not your contacts message you.
