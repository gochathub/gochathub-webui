# Getting started

Sign in with the username and password your administrator gave you. Accounts are created on the server, so there is no sign-up page.

If your account uses two-factor authentication, the sign-in form asks for a second step. Enter the 6-digit code from your authenticator app, or one of your backup codes.

## Install as an app

Your browser can install goChatHub as an app. Look for the install option in the address bar or the browser menu. Push notifications work best from the installed app.

## Where things are

- Conversations lists your rooms.
- Contacts lists people on your server.
- Settings holds your account, privacy, appearance and notification options.
