# Getting started

Sign in with the username and password your administrator gave you. Accounts are created on the server, so there is no sign-up page.

If your account uses two-factor authentication, the sign-in form asks for a second step. Enter the 6-digit code from your authenticator app, or one of your backup codes. See [Account and security](/help/account-security).

## Where things are

The bar on the left (along the bottom on a phone) switches the sidebar:

- Conversations lists your rooms. See [Conversations and groups](/help/rooms).
- Contacts lists people on your server.
- Notifications holds invitations. See [Notifications](/help/notifications).
- Settings holds your account, privacy, appearance and notification options.

The question-mark button opens this help. On a phone it is in the profile menu.

## Install as an app

Your browser can install goChatHub as an app. Look for the install option in the address bar or the browser menu. The installed app is the best way to get notifications when the window is closed.

When a new version is ready, a banner asks whether to upgrade. Choose Upgrade to reload with the new version, or Later to keep working. It asks again later.

If something does not work, try [Troubleshooting](/help/troubleshooting).
