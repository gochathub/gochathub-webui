# Writing and finding messages

## Send

Type in the box at the bottom and press Enter to send. Shift+Enter starts a new line. Inside a list or a code block, Enter keeps its normal job, so use Ctrl+Enter (Cmd+Enter on a Mac) to send from there.

The paperclip button adds files. See [Attachments](/help/attachments). The smiley button opens the emoji picker. You can also type a shortcode such as "tada" between two colons, and it turns into the emoji.

If you leave a message unsent, the conversation list shows a draft preview next to it.

## Formatting

Messages understand a small set of Markdown. Each line below is one example:

```
**bold**
*italic*
~~strikethrough~~
`inline code`
[link text](https://example.com)
> a quote
- a list item
1. a numbered item
# a heading
```

Put a block of code between two lines that contain only three backticks.

HTML is not allowed. Anything that looks like a tag is shown as plain text.

## Mention someone

Type @ and start a username. A list of suggestions appears. Pick one and the name is highlighted for everyone in the conversation.

## Message actions

Right-click a message to open its menu.

- Reply quotes the message above your next one.
- Copy puts the text on your clipboard.
- Pin shows the message in a bar at the top of the conversation. The pin bar has buttons to hide or close it.
- Select lets you pick several messages. Select All and Cancel appear at the top.
- Delete Message removes it for everyone. You can delete your own messages. Room admins and server admins can delete any message in their rooms. The app asks you to confirm first.

## Search

Press the magnifier in the conversation header and type. The server searches the messages in that conversation. Selecting a result scrolls back to the message and highlights it, loading older messages on the way if needed.

## Times

Timestamps use your browser's time zone. Days are separated by a divider with the weekday and date.
